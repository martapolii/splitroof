# SplitRoof

SplitRoof is a responsive web application for roommates and couples who share household expenses. It helps users record expenses, split costs, see balances, record settlements, manage budgets, and review spending.

## Project

- **Course:** COMP 231 Software Development Project I
- **Team:** Eightfold, Group 1
- **Project board:** [GitHub Project](https://github.com/users/martapolii/projects/6)
- **Status:** In development

## Planned features

- Account registration and login
- Create or join a household
- Add expenses and split them equally or by custom amounts
- View running balances and settlement history
- Set monthly category budgets and view warnings
- View a household dashboard and reports

## Technology

- React and JavaScript
- Node.js and Express
- Firebase Cloud Firestore
- JWT authentication and hashed passwords
- Vercel for the frontend
- Render for the backend
- Jest, Supertest, and React Testing Library

## Repository structure

```text
frontend/       React client

```

The folders above describe the planned structure and may be added as implementation progresses.

## Development workflow

1. Select or create an issue in the [GitHub Project](https://github.com/users/martapolii/projects/6).
2. Create a branch for the issue.
3. Make the change and add or update relevant tests.
4. Open a pull request linked to the issue.
5. Request review from another team member before merging.

Do not commit passwords, API keys, Firebase credentials, or other secrets. Use environment variables for local and deployed configuration.

## Scope exclusions for Release 1.0

The current scope does not include native mobile apps, bank or payment integration, real payments, multiple currencies, receipt OCR, notifications, recurring expenses, social login, or a separate administrator console.
